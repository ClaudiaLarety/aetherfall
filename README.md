# Aetherfall

A 3D platformer built with JavaScript and three.js. Jump across floating platforms to reach the golden goal.

**Play it:** https://claudialarety.github.io/aetherfall/

## Controls
- Move: W A S D or arrow keys
- Jump: Space

## Features
- 3D world with a third-person camera
- Gravity, jumping and platform collision
- Respawn when you fall
- Goal platform with a win message

## How to run
Open `index.html` in any browser. No install needed.

## Built with
HTML, JavaScript, three.js

## Roadmap
- Collectible coins and a score
- Moving platforms
- Timer and more levels
